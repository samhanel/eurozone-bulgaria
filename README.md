# FuturCreative - Bulgarian Eurozone Dual Currency

This repository contains a simple WooCommerce plugin that displays prices in Bulgarian Lev (BGN) and Euro (EUR) across the store. The euro amounts are calculated with the fixed exchange rate **1 EUR = 1.95583 BGN**.

## Installation
1. Copy the `futurcreative-dual-currency` folder into your WordPress `wp-content/plugins` directory.
2. Activate **FuturCreative - Bulgarian Eurozone Dual Currency** from the Plugins menu in WordPress.
3. Configure the plugin under **WooCommerce → Dual Currency**.

## Features
- Toggle dual currency display.
- Custom euro label and position relative to the BGN price.
- Choose where euro prices appear using the set of location checkboxes.

The plugin is designed for modern WordPress versions and WooCommerce themes.
